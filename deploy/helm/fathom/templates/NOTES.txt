  kubectl -n {{ .Release.Namespace }} rollout status deployment/{{ include "fathom.fullname" . }}

Open it:

  The pod uses the node's network: http://<node address>:{{ .Values.server.port }}/ answers as well.

{{ if .Values.admin.enabled -}}
Sign in as "{{ .Values.admin.username }}". The password is in the Secret "{{ include "fathom.adminSecretName" . }}":

  kubectl -n {{ .Release.Namespace }} get secret {{ include "fathom.adminSecretName" . }} -o jsonpath='{.data.{{ .Values.admin.passwordKey }}}' | base64 -d; echo

The user is created once. Change the password in the app afterwards (the
Secret then no longer matches), and add people under Settings › Users.
{{- else -}}
No admin user is created (admin.enabled=false). Unless FATHOM_AUTH is set or
users.json already has users, Fathom needs no login and every visitor is an
admin. Add a user at any time:

  kubectl -n {{ .Release.Namespace }} exec -it deployment/{{ include "fathom.fullname" . }} -- fathom user add <name> --role admin
{{- end }}
