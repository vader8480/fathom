## Interface details (no deviations from §7.4.2 signatures)

- `library.save_custom_template` raises `ValueError` (with `.problems`) for an invalid template and
  `FileExistsError` for a built-in id without `override`. `delete_custom_template` raises
  `PermissionError` for built-ins and `FileNotFoundError` when absent. Listing entries carry
  `source` = `builtin | extension | custom | project` (server checks `custom` before delete).
- `floorplan.UnsupportedPlan.code` ∈ `dwg_unsupported | pdf_unsupported | unsupported_format |
  binary_dxf`. Files > 50 MB and SVG/XML with `<!ENTITY>` declarations raise `unsupported_format`.
- `floorplan.detect_plan_kind` returns `png jpg svg pdf drawio dxf dwg dxf-binary unknown`.
- `cables.to_csv(schedule)` is a generic `{"columns","rows"}` → CSV helper (used by builds and CLI).
- `cables.cable_schedule` JSON rows carry names in `from_device`/`from_port`/… plus `*_id` keys,
  `medium` (key) and `medium_label`, `discipline`, `length` in settings units + `length_unit`,
  `length_m`; the result also has `bundles` and `totals`.
- `network.ip_schedule` rows: `switch_port` shows the switch port's physical *name*.
- `bom.inventory_schedule` column labels equal their keys (FR-INV-04 asks for `serial`/`asset_tag`
  columns in the CSV).
- `export.write_build(...)` returns the v0.2 strings plus `files` and `notes` (newline-joined).
  With `doc` it always writes `build-notes.txt` (first line = build summary). Extra helpers:
  `export.public_base(doc, base_url)`, `export.build_doc(...)`.
- Overlay route kinds: `dante`, `console` (auto source → stage box from the v0.2 console merge),
  `videohub`. Videohub routes are internal (`sdi-in-<i>` → `sdi-out-<o>` on the router).
- Eos overlay fixtures: id `eos-<channel>`, two DMX ports (`dmx-in`, `dmx-thru`); overlay `dmx` rows for
  matched and auto fixtures (`source: "eos"`), `detail[dev].lighting` = type/position/purpose/….
- `FATHOM_PDF_RASTERIZER` template placeholders: `{in} {out} {page} {dpi}`; `{page}` is 0-based; any
  `out*.png` written in the temp dir is accepted (pdftoppm `-singlefile` appends `.png`).

## Open questions / spec defects

1. **Appendix C.3, `encode("x" * 2332, "M")` → version 40** cannot hold: ISO/IEC 18004 byte capacity of
   40-M is 2331 bytes (2334 data codewords − 20 header bits). The encoder follows the standard
   (2331 fits, 2332 raises `ValueError`); C.1 and C.2 match bit for bit. T1: please test 2331.
2. Legacy Dante import creates cards on a room's map for Dante devices that live in *other* rooms
   (e.g. CHAPEL-TF on the Main Auditorium map), because the v0.2 merge only sees that room's flow project.
   In the overlay these are mapped back to the real devices (no duplicate overlay device). W1/W5 may want
   the flow adapter to expose such devices as external ghosts instead.
3. FR-PLN-01 wording ("retired hidden unless `all`") vs §4.4.6 (`everything` includes retired): BOM
   follows §4.4.6; spares are always counted in BOM/inventory.
